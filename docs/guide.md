# nost - 사용 설명서

> stary no more — 더 이상 헤매지 마세요.

nost는 자주 쓰는 앱, 폴더, 웹사이트, 명령어를 한 곳에 모아두고
단축키 하나로 즉시 꺼내 쓸 수 있는 데스크톱 런처입니다.

---

## 기본 조작

| 동작 | 설명 |
|------|------|
| **Alt + 4** | nost 호출 / 숨기기 (설정에서 변경 가능) |
| **좌클릭** | 카드 실행 (앱 실행, 폴더 열기, URL 이동 등) |
| **더블클릭** | 앱/윈도우 전체화면 실행 |
| **꾹 누르기** | 방향 선택 메뉴 (모니터 이동, 스냅, 삭제) |
| **우클릭 드래그** | 카드 순서 변경, 스페이스 간 이동 |
| **Tab** | 다음 프리셋으로 전환 |
| **ESC** | 현재 모드 종료 → 다이얼로그 닫기 → 앱 숨기기 |

---

## 프리셋 (Preset)

완전히 독립된 3개의 작업 공간을 한 앱 안에 둘 수 있습니다.

- 제목 바의 **1 / 2 / 3** 알약 버튼으로 전환
- 알약을 **더블클릭**해서 이름 변경 (예: 1 → "업무", 2 → "개인")
- 각 프리셋은 자체 스페이스·노드·덱·플로팅 뱃지를 소유
- 설정·단축키·테마는 모든 프리셋이 공유
- 슬래시 `/1` `/2` `/3` 또는 **Tab** 키로도 전환

---

## 스페이스 (Space)

카드를 그룹으로 분류하는 폴더 개념입니다.

- 상단 **+** 버튼으로 새 스페이스 생성
- 스페이스 헤더의 **...** 메뉴로 이름 변경, 삭제, 복제, 다른 프리셋으로 이동
- 스페이스 헤더를 **좌클릭 드래그**해서 순서 변경
- 두 스페이스를 가로로 **페어(pair)** 로 묶어 한 행에 나란히 배치 가능

---

## 카드 (Card)

각각의 아이템을 나타냅니다.

### 카드 종류
| 종류 | 설명 |
|------|------|
| **앱** | .exe 실행 파일 |
| **폴더** | 탐색기로 폴더 열기 |
| **URL** | 브라우저에서 웹페이지 열기 |
| **윈도우** | 이미 열린 창 포커스 |
| **텍스트** | 클립보드에 복사 |
| **명령어** | 터미널 명령 실행 |

### 카드 추가 방법
1. **빠른 추가**: 스페이스의 + 버튼 → 폴더/파일 선택
2. **수동 추가**: 스페이스의 ... 메뉴 → 아이템 추가
3. **스마트 스캔**: 스페이스의 ... 메뉴 → 앱 스캔 (자동 추천)
4. **클립보드**: 커맨드바에서 `/clipboard` 입력

### 꾹 누르기 (Hold) 메뉴
카드를 0.5초 이상 꾹 누르면 방향 메뉴가 나타납니다:
- **↑ 위**: 모니터 이동 (W/A/S/D 방향)
- **← 왼쪽**: 왼쪽 반 스냅
- **→ 오른쪽**: 오른쪽 반 스냅
- **↓ 아래**: 카드 삭제

## 도구 모드

좌측 사이드바의 도구 버튼으로 활성화합니다. **ESC**로 종료.

### 고정 모드 (Pin)
카드를 클릭하면 핀 토글 → 핀 고정된 카드는 정렬에서 상단 유지.
핀은 카드 우측 상단의 북마크 아이콘으로 시각화됩니다.

### 노드 편집 (Node)
2~3개 카드를 선택하여 분할 화면으로 동시 실행합니다.
1. 허브(hub) 버튼 클릭
2. 카드를 순서대로 클릭 (또는 우클릭 드래그로 패널에 드롭)
3. 이름 입력 후 저장

### 덱 편집 (Deck)
여러 카드를 순차적으로 실행합니다.
1. 스택(stacks) 버튼 클릭
2. 카드를 클릭하여 덱에 추가
3. 이름 입력 후 저장

### 청소 모드 (Clean)
고정되지 않은 카드를 한 번에 정리합니다.
- 슬래시 `/clean` 또는 `/clean n` 으로도 실행 가능

### 컨테이너 (Container) — Pro
한 카드 슬롯 안에 여러 카드를 묶어 폴더처럼 사용합니다.
컨테이너 위에서 잠시 머무르면 4방향 슬롯이 펼쳐져 카드를 드롭할 수 있습니다.

> 모드 진입 시 다른 모드는 자동 종료됩니다 (상호 배타).

## 플로팅 뱃지 + 미니 윈도우

스페이스·노드·덱을 nost 창 밖으로 분리해 **원형 뱃지**로 둘 수 있습니다.

- 각 헤더의 **↗ open_in_new** 버튼 → 원형 뱃지로 착지
- 뱃지 **클릭** → 미니 윈도우 팝오버
  - 스페이스: 카드 목록(고정 먼저) → 클릭 즉시 실행
  - 노드: 아이템 + 하단 "묶음 실행"
  - 덱: 아이템 + 하단 "순차 실행"
- 뱃지 **드래그**로 이동 · nost 창 위에 드롭하면 자동 해제
- **우클릭 메뉴**: 실행 / 플로팅 해제 / 모든 플로팅 해제
- 재시작해도 상태 유지

## 커맨드바 (/)

검색창에 `/`로 시작하는 명령을 입력합니다.

| 명령 | 설명 |
|------|------|
| `텍스트` | 카드 전체 검색 (실시간 필터) |
| `/n-m` | n번 스페이스의 m번 카드 실행 |
| `//n` | n번 노드 실행 |
| `/1` `/2` `/3` | 프리셋 전환 |
| `/new 이름` | 새 스페이스 생성 |
| `/pin n-m` | 해당 카드 핀 토글 |
| `/clipboard` | 클립보드 → 첫 번째 빈 슬롯에 저장 |
| `/clipboard n-m` | 클립보드 → n번 스페이스 m번 위치에 저장 |
| `/tile n-m n-m` | 두 카드를 분할 화면으로 실행 |
| `/clean` `/clean n` | 고정되지 않은 카드 청소 (n 없으면 전체) |
| `/theme` | 다크 / 라이트 테마 전환 |
| `/opacity N` | 런처 투명도 (0~100, 예: `/opacity 85`) |
| `/50` `/75` `/100` | 런처 창 크기 조정 (화면 비율, 중앙 배치) |
| `/setting` | 환경설정 열기 |
| `/tutorial [id]` | 튜토리얼 시작 |
| `/?` | 도움말 |

---

## 튜토리얼

설정 → 일반의 "기본 사용법" 또는 커맨드바 `/tutorial` 로 실행합니다.

- **선언적 투어 시스템**: `data-tour-id` 앵커 기반 — DOM 리팩터에도 안정
- 진행 방식: "대상 클릭 대기" / "다음 버튼" / "조건 자동 통과"
- 기본 탑재: `presets`, `slash`, `floating`
- 사용자가 작업 중이면 자동으로 대기 (드래그 / 모달 / 편집 진행 중엔 끼어들지 않음)

## 모니터 설정

카드별로 실행할 모니터를 지정할 수 있습니다.
- 카드를 꾹 눌러서 ↑ 방향으로 모니터 번호 전환
- 노드/덱에서도 모니터 지정 가능
- 설정 > 모니터에서 모니터 방향(WASD) 설정
- 다중 DPI 환경(예: 노트북 125% + 외부 모니터 100%) 자동 보정

---

## 브라우저 확장 (nost Bridge)

Chrome / Whale 브라우저에서 탭 스캔과 타일 분할을 사용하려면
확장 프로그램이 필요합니다.

- **설정 > 확장** 탭에서 **확장 설치하기** 클릭 (Chrome 웹 스토어 페이지 열림)
- 백그라운드에서 레지스트리 작성 → Chrome 우상단 알림에서 **활성화** 한 번으로 끝
- 모든 통신은 `127.0.0.1:14502` 로컬 루프백만 사용 (자세한 내용은 PRIVACY.md)

## Pro

무료 / Pro 차이가 있습니다.
- **무료**: 프리셋 1번만, 기본 카드/스페이스/노드/덱 사용 가능
- **Pro**: 프리셋 1·2·3, 컨테이너, 플로팅 뱃지 무제한

> **베타 기간 한정**: 결제 시스템 도입 전까지 모든 사용자가 Pro 무제한입니다.
