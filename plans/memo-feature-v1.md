# 메모 기능 v1 — "사라지는 메모" 기획안

> **컨셉:** 7일 뒤에 사라지는 메모. 한 번 톡 치면 7일 더.
> 정리를 시간이 대신 해주는, 결정 없는 메모장.
>
> **핵심 명제:** 캐쥬얼 = 본질. nost가 사용자 의식에 개입하지 않는다.
> 사용자는 그냥 *쓰고*, *닫고*, 잊는다. 살아남는 건 사용자가 자연스럽게
> 다시 만진 것뿐.

---

## 포지셔닝

노션 vs 메모장 사이의 빈 자리:

| | 노션류 | **nost 메모** | 시스템 메모장 |
|--|------|--------------|------------|
| 켜는 비용 | 높음 (앱·로그인·페이지 탐색) | **0.2초 (단축키)** | 낮음 |
| 정리 비용 | 카테고리 결정 필요 | **없음 (시간이 정리)** | 누적 → 폭탄 |
| 시간 지평 | 장기 (영구) | **중기 (7일 작업기억)** | 의도 없음 |
| 손실 위험 | 거의 없음 | 신경 안 써도 안전 | Ctrl+W 폭탄 |

→ **mid-term memory** = nost 메모의 자리. AI 시대 "프롬프트 임시
저장 / 회의 받아적기 / 5분 뒤 처리할 것" 의 외부화.

---

## 핵심 행동 문법

모든 액션 = **딸깍 1회.** 결정·확인·저장 다이얼로그 없음.

| 의도 | 액션 | 결과 |
|------|------|------|
| 떠오른 거 적기 | 카드 그리드의 + 버튼 → "메모" | 메모 카드 생성 + 에디터 진입 |
| 저장 | **없음 — 타이핑이 곧 저장** | 500ms 디바운스 자동 저장 |
| 닫기 | Esc 또는 카드 외부 클릭 | 사라짐. 카드만 그리드에 남음 |
| 7일 더 살리기 | 카드 우하단 **점 1번 톡** | TTL 리셋 (+기본 수명) |
| 영원히 보관 | 핀 토글 | TTL 해제, 일반 카드처럼 영구 |
| txt로 내보내기 | 카드 ⋯ → "파일로 내보내기" | 메모 → txt 파일 → **파일 카드로 변신** |
| 만료 후 되살리기 | 휴지통에서 복원 | TTL 재할당 |

> **암묵 규칙:** 편집(타이핑) = TTL 자동 리셋. 읽기만 = 변화 없음.
> "메모를 어떻게 분류할까"를 사용자가 결정 안 해도 됨. **행동이 분류함.**

## 세 갈래의 영구화 경로

같은 메모도 어떻게 쓰느냐에 따라 운명이 갈림:

| 경로 | 의미 | 결과 |
|------|------|------|
| **편집해서 계속 살리기** | "지금도 작업 중" | 휘발성 유지, 자연 갱신 |
| **핀** | "안 만지지만 있어야 해" | 영구 메모 카드 |
| **txt로 내보내기** | "졸업. 외부에서도 쓰고 싶어" | txt 파일 + 파일 카드 |

세 길이 겹치지 않음 = 깔끔.

## 시각 언어

### 카드 모양
```
┌─────────────────────────────┐
│  오늘 미팅 노트              │  ← 첫 줄이 제목
│  - 9시 백엔드 싱크           │
│  - GPT 프롬프트 다듬기...    │
│                             │
│  ●●●●●○○   3일 남음    ⋯   │  ← 수명 게이지 + 살리기 점
└─────────────────────────────┘
```

- **수명 게이지 7칸** — 매일 한 칸씩 꺼짐. 직관적.
- **3일 이하**: 카드 살짝 페이드 (opacity 0.85). "곧 가요" 신호.
- **24h 이하**: 노란 점, 마지막 칸 깜빡임.
- **만료**: 휴지통으로. 그리드에서 사라짐.

> TTL은 **불안**이 아닌 **안도**의 시각화. "내가 안 건드리면 알아서
> 정리되는구나" 라는 감정이 핵심.

### 에디터 (의도적으로 빈약)
- 마크다운 미니멀: `- ` 리스트, `**굵게**`, `[ ]` 체크박스. **그게 끝.**
- 헤딩 / 표 / 코드블록 / 이미지 첨부 **없음** (노션 영역으로 양보)
- 글자 수 + 수명 표시만 하단
- 자동 줄바꿈, 페이지 개념 없음
- 폰트·색상 메뉴 없음

## 자동 폐기 — 2단계

```
[활성] ──TTL 만료──▶ [휴지통] ──보관 만료──▶ [영구 삭제]
  ↑                       ↓
  └── 되살리기 (TTL 리셋) ──┘
```

- **부재 감지·검토창 없음.** 노트북 2주 덮어두고 와도 그냥 정돈된
  그리드를 만남. 이게 *캐쥬얼*.
- 만료 판정은 *읽을 때* (`Date.now() > expiresAt`)로 충분.
  cron 백그라운드 안 돌림.

## 설정 화면 (5줄)

```
[설정 › 메모]

▸ 새 메모 기본 수명
  ( ) 1일   ( ) 3일   ( • ) 7일   ( ) 14일   ( ) 30일
  ( ) 직접 입력  [   ]일   (1~90일)
  ↳ 새 메모가 이 기간 뒤 휴지통으로 갑니다. 기존 메모와
    핀 고정한 메모는 영향 없음.

▸ 휴지통 보관 기간
  [ 24시간 ▼ ]   24시간 · 3일 · 7일

▸ 메모 내보내기 폴더
  [ %APPDATA%/nost/memos/ ]                   [변경]

────────────────────────────────────────────
일괄 정리       [ 휴지통 비우기 ]   [ 모든 메모 +7일 ]
```

### 확정된 결정 사항

| # | 결정 |
|---|------|
| 1 | TTL은 메모에 박힌 값. 설정 변경은 신규 메모만 영향. |
| 2 | 톡 살리기 = 기본 수명과 동일 (분리 옵션 없음 — 복잡도 회피) |
| 3 | "안 사라짐" 기본값 불가. 1~90일만. (제품 컨셉 보호) |
| 4 | 2단계 자동 폐기 (만료 → 휴지통 → 영구 삭제) |
| 5 | 부재 감지 / 검토창 **없음.** 캐쥬얼이 본질. |
| 6 | 편집=리셋, 읽기=무변화, 톡=리셋, 핀=해제 |
| ★ | 일괄 +7일은 설정 안에 (의도적으로 멀리 — 비상구) |

## 데이터 스키마

```ts
type Memo = {
  id: string;
  body: string;            // 첫 줄 = 제목
  createdAt: number;       // ms (UTC)
  expiresAt: number;       // ms (UTC) — 절대값
  lastTouchedAt: number;   // 편집 또는 톡
  pinned: boolean;         // true면 expiresAt 무시
  trashedAt?: number;      // 휴지통 진입 시각
  // 카드 인프라 호환
  cardId: string;          // 카드 그리드의 카드 ID와 동기
  spaceId: string;
  presetId: string;
};

type MemoSettings = {
  defaultTtlDays: number;       // 1~90 (검증 강제)
  trashRetentionHours: 24 | 72 | 168;
  exportFolder: string;          // 기본 %APPDATA%/nost/memos/
};
```

저장: `electron-store` (기존 사용 중). 메모 본문은 별도 키로 분리해
대용량 사용자에서도 메인 store 부풀지 않게.

## txt 내보내기 동작

1. 카드 ⋯ → **"파일로 내보내기"**
2. `${exportFolder}/${slugify(첫줄)}_YYYYMMDD.txt` 로 저장
3. 메모 카드 → **파일 카드로 변신** (기존 파일 카드 인프라 재사용)
4. 클릭 → OS 기본 편집기로 열림
5. 원래 메모 데이터 **삭제** (휴지통 안 거침 — 이동이지 복사가 아님)
