# UI 어휘 사전 — Korean UX Vocabulary SSOT

> nost UI 전반의 한국어 동사 / 명사 / 라벨 통일. 사용자가 "왜 어떤 데선 '실행', 어떤 데선 '발사' 라고 하지?" 의문 0초.
>
> 작성: 2026-05-14. 갱신 트리거: 새 UI surface 추가 시 / 사용자 피드백 시.
>
> **튜토리얼 문구는 별도 SSOT** → [`plans/tutorial-writing-style.md`](./tutorial-writing-style.md). 본 문서는 UI 위젯 라벨/hover/토스트 영역.

---

## §1. 핵심 원칙

1. **격식 한국어 (~다 / 입니다체)** — 캐주얼/유행어 금지 ("발사", "진짜최종", "갓성비" 등)
2. **명사 + 조사 + 동사** 순서, 1-2단어 이내 — "앱 실행" ✅ / "앱을 실행해주세요" ❌
3. **동사 통일** — 같은 동작은 어디서나 같은 동사
4. **이모지는 토스트 / 헤드라인 한 곳에만** — body 텍스트엔 안 씀
5. **영어 식별자는 영어 그대로** — "Hex 복사" / "ESC 로 닫기" / "Alt+4"

## §3. 호버 힌트 패턴 (`HOVER_HINT` 헬퍼)

`frontend/src/widgets/widgetTokens.ts::HOVER_HINT()` 통과 필수. 형식:

```
<제스처> : <동사>
```

### Good ✅

```
클릭 : 앱 실행
길게 누르기 : ↑ 수정 ↓ 모니터 ← 새 창 → 복사
왼쪽으로 스와이프 : 마크다운으로 복사
```

### Bad ❌

```
짧게 : 발사            ← "짧게" 캐주얼 / "발사" 유행어
길게 : 4방향           ← 너무 추상적
스와이프 좌 : 마크다운 ← 어순 어색
```

## §4. 금지어 / 회피어 리스트

| 금지 | 대체 |
|---|---|
| 발사 | 실행 |
| 짧게 / 길게 (단독) | 클릭 / 길게 누르기 |
| 깔깔 / 진짜 / 정말 | (생략) |
| 진짜최종 / 갓성비 / 꿀 | (생략) |
| 클릭해주세요 | 클릭 |
| 변경하시려면 | 변경하려면 |
| 입니다 / 합니다 (긴 종결) | 입니다 / 됩니다 — body 텍스트 한정. 짧은 label 은 명사형 |

## §5. 토스트 길이 + 포맷

### 1줄 토스트 (기본)

```
"메모로 저장됨 · 즐겨찾기"      ← 결과 · 위치
"카드 1개 삭제됨"
"확장이 깨어있지 않아요"
```

- 30자 이내 권장
- `·` 구분자로 추가 컨텍스트
- 마침표 X

### 액션 포함 토스트

```
{
  title: "v1.3.33 다운로드 완료",
  actions: [{ label: '지금 설치', icon: 'restart_alt', onClick: ... }],
}
```

- 액션 label 은 동사 (없 명사) — "지금 설치" / "이어서" / "다시 시도"

### Korean Markdown 메타 (release notes 등)

자유. 문장체 OK. 이모지 헤더 적극 활용.

## §6. 알림센터 카테고리 뱃지

`NotificationPanel::deriveCategory` 가 자동 derive (intent 또는 dedupKey 패턴). 라벨은:

| 카테고리 | 라벨 (정식) | 색상 |
|---|---|---|
| 튜토리얼 | **튜토리얼** | `var(--accent)` |
| 브라우저 확장 | **확장** | `var(--text-muted)` |
| 업데이트 | **업데이트** (kind 라벨로 표시) | `var(--text-color)` |
| 결제/Pro | **프로** | `var(--color-destructive)` |
| 시스템 오류 | **시스템** | `var(--color-destructive)` |
| 발견 / 추천 | **발견** | `var(--accent)` |
| 일반 팁 | **팁** | `var(--text-muted)` |

대괄호 [ ] 는 UI 컴포넌트가 자동 처리 — title 텍스트에 직접 적지 말 것.

## §7. SettingsDialog 그룹 / 탭 라벨

[`SettingsDialog.tsx::TAB_GROUPS`](../frontend/src/components/SettingsDialog.tsx) SSOT. 변경 시 본 문서 동기화.

```
나의 nost     · 계정          · 데이터
작업 환경     · 테마 및 색상  · 동작            · 플로팅 및 모니터
콘텐츠 규칙   · 메모          · 문서
도움          · 튜토리얼      · 확장
```

명명 원칙:
- 그룹 헤더 = 명사구 (관계격 X)
- 서브탭 = 1-2단어
- "및" 사용 OK (테마 및 색상, 플로팅 및 모니터)
- "설정" 같은 메타 단어 회피 — 이미 다이얼로그 제목이 설정

## §8. 에러 메시지 패턴

### Good ✅

- "URL 은 `https://` 또는 `http://` 로 시작해야 합니다"
- "올바른 폴더 경로를 입력하세요 (예: `C:\Users\...`)"
- "백업 파일 형식이 올바르지 않습니다"

### Bad ❌

- "Invalid URL"  ← 영어
- "URL 잘못됐어요" ← 비격식
- "URL 형식 오류가 발생했습니다. https:// 또는 http://로 시작하는 URL을 입력해주세요." ← 너무 김

규칙:
- 무엇이 잘못됐는지 + 무엇을 입력해야 하는지 (예시 포함)
- 50자 이내
- "~ 합니다" 격식

## §9. 단축키 표기

영문 단축키 그대로:

```
Alt+4
Ctrl+Z
Shift+Tab
Enter
ESC
```

### 표기 규칙

- `+` 로 키 조합 (공백 없음)
- 함수 키는 `F1`, `F12` 그대로
- 마우스 동작은 한국어 ("우클릭", "더블클릭")
- 한국어 동작과 영어 키 혼합: "Enter 로 저장", "Alt+4 로 호출"

## §10. 점검 / 회귀 시나리오

새 UI 텍스트 추가 / 수정 시 자체 체크리스트:

- [ ] §2 동사 통일표 매핑 확인 — 새 동사면 표에 추가
- [ ] §3 호버 힌트 패턴 (`<제스처> : <동사>`) 준수
- [ ] §4 금지어 검색 (`grep -rn '발사\|짧게 :\|길게 :' frontend/src`)
- [ ] §5 토스트 30자 이내 (시각 확인)
- [ ] §6 카테고리 뱃지 자동 매핑 — `[튜토리얼]` 같은 prefix 직접 적지 않음
- [ ] 영어 잔재 검색 (`grep -rE "title='[A-Z]"`)

### 자동 grep 명령

```bash
# 금지어 검색
grep -rn '발사' frontend/src/components frontend/src/widgets

# 캐주얼 어휘 검색 (호버 힌트 외)
grep -rn '짧게 :' frontend/src
grep -rn '길게 :' frontend/src

# 한국어 + 영어 혼용 검색
grep -rE "'.*[가-힣].*[A-Z]{2}.*'" frontend/src/components | head
```
